Direct-Manipulation Matrix

Start dragging on any number and release to sort:

  1. Drag right → to sort the selected row in ascending order.
  2. Drag left ← to sort the selected row in descending order.
  3. Drag down ↓ to sort the selected column in ascending order.
  4. Drag up ↑ to sort the selected column in descending order.
  5. Drag diagonally down-right ↘ to sort only the selected rectangle along both axes in ascending order.
  6. Drag diagonally up-left ↖ to sort only the selected rectangle along both axes in descending order.

Start on any number and drag to sort. Horizontal gestures sort a row, vertical gestures sort a column, and diagonal gestures sort the highlighted rectangular area. To sort the entire matrix, drag diagonally between opposite corners.
