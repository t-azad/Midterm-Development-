Direct-Manipulation Matrix

Specific ways to sort using drag action:

  1. Drag right → to sort a row in ascending order.
  2. Drag left ← to sort a row in descending order.
  3. Drag down ↓ to sort a column in ascending order.
  4. Drag up ↑ to sort a column in descending order.
  5. Drag diagonally down-right ↘ to sort only the highlighted cells along both axes in ascending order.
  6. Drag diagonally up-left ↖ to sort only the highlighted cells along both axes in descending order.

Start on any cell and drag based on the specific sorting (ascend or descend) you intend. Dragging horizontal sorts a row, while dragging vertically sorts a column, and diagonal dragging sorts both the row and column highlighted in an area. To sort the entire matrix, drag diagonally between opposite corners.
